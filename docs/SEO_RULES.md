# SEO Rules

Every production project must include:

- Unique title and meta description for indexable pages.
- Canonical URLs.
- robots.txt and sitemap.xml.
- Semantic heading hierarchy with one clear page-level H1.
- Open Graph metadata.
- Structured data where it accurately represents the page.
- Descriptive image alt text where images convey information.
- Internal linking between relevant commercial and informational pages.
- Clean, stable and human-readable URLs.
- Redirect mapping when replacing existing URLs.
- No fabricated claims, reviews, addresses, prices or structured-data values.

SEO changes must pass technical validation before production deployment. Content quality and search intent take priority over keyword repetition.
