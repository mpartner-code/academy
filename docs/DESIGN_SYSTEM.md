# Design System

## Goal
Create premium, fast, accessible commercial websites without generic AI-looking UI.

## Core rules
- Mobile-first and fully responsive.
- Use a consistent 8px spacing rhythm.
- Keep content inside a maximum 1280px container unless a section is intentionally full-bleed.
- Use no more than two font families per project.
- Prefer strong typography, whitespace and photography over decorative effects.
- Avoid excessive gradients, glass effects, cards and rounded containers.
- Maintain WCAG-friendly contrast and visible keyboard focus states.
- Every interactive element must have hover, focus and disabled states where relevant.

## Project customization
Each client project must define brand colors, typography, imagery direction, component variants and page-specific visual rules before production UI work begins.
